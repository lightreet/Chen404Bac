# 动漫风樱花优化

## 目标

把首页樱花改成更轻柔梦幻的日系动画背景风格，重点不是再加风，而是让它更有远近层次、景深感和空气感。

## 当前问题

- 当前樱花主要像统一规则的粒子系统，近景/远景差异不够明显。
- 水平风感和整体左飘比较强，更像特效层，不够像动画背景中的“空气里飘着花瓣”。
- 花瓣虽然已做成粉色，但层次主要靠单片渐变，缺少前中后景的大小、模糊、透明度变化。

## 改造方向

- 修改 [Chen404Fro/src/components/SakuraOverlay/SakuraOverlay.vue](d:\code_repo\Chen404\Chen404Fro\src\components\SakuraOverlay\SakuraOverlay.vue)
- 在 `SakuraPetal` 上增加“景深层级”概念，例如 `depth` 或 `layer`：
- 远景：更小、更淡、更慢、轻微模糊
- 中景：主视觉层，数量最多
- 近景：稍大、稍亮、旋转更明显，但数量少
- 调整花瓣生成逻辑 `createPetal()`：
- 不再让所有花瓣共享接近的尺寸/透明度区间
- 按层级分配不同的 `size / opacity / blur / speedY / speedX / sway`
- 调整绘制逻辑 `drawPetal()`：
- 保留当前樱花花瓣大体形状，但进一步弱化中心高光
- 让远景花瓣边缘更柔和，近景花瓣稍清晰
- 用更低强度的阴影或模糊营造景深，而不是靠明显白块
- 调整运动逻辑 `animate()`：
- 降低“强风吹散”感，减弱统一的全局横向风
- 保留轻微左右摆动和旋转，但让远景花瓣更稳、近景花瓣更灵动
- 目标是“飘”而不是“扫”

## 关键实现点

- 当前文件里最值得动的部分：
- `interface SakuraPetal`
- `createPetal()`
- `drawPetal()`
- `animate()`
- 这次优化不需要改首页页面结构，也不需要动 [Chen404Fro/src/views/Home/Home.vue](d:\code_repo\Chen404\Chen404Fro\src\views\Home\Home.vue) 的 Hero 布局。

## 建议效果

- 视觉上应更接近日系动画背景中的“淡粉花瓣漂浮层”
- 远处会有更小、更淡、更虚的花瓣
- 近处会有少量略大但不突兀的花瓣
- 整体画面更柔、更梦幻、更像氛围层，而不是前景特效

## 可选细化

- 如果第一轮后你还觉得不够“动漫”，下一步可以再补：
- 轻微透明度呼吸变化
- 少量失焦花瓣
- 不同轮廓变体（1-2 种微差异花瓣）
