# 优化首页波线

## 问题判断

当前视觉像直线，核心原因在于：

- `HeroWave` 中所有线条共用同一条 `basePath`，层间差异主要靠平移和轻微缩放，真实波形差异不够。
- 当前 `basePath` 振幅偏小且节奏过均匀，远看容易被识别成一条白色分割带。
- `Home.vue` 里的 `hero-wave` 容器高度较矮，进一步压缩了波形的可见起伏。

关键位置：

- [d:\code_repo\Chen404\Chen404Fro\src\components\HeroWave\HeroWave.vue](d:\code_repo\Chen404\Chen404Fro\src\components\HeroWave\HeroWave.vue)
- [d:\code_repo\Chen404\Chen404Fro\src\views\Home\Home.vue](d:\code_repo\Chen404\Chen404Fro\src\views\Home\Home.vue)

## 实施方案

### 1. 让每层拥有“不同的真实波形”

在 `HeroWave.vue` 中把单一 `basePath` 升级为按层生成的 path 集合，而不是所有线条复用同一路径。

做法：

- 新增一个轻量的 `buildWavePath(depth, index)` 方法。
- 以固定锚点生成 5-7 段连续三次贝塞尔曲线，整体保持“类正弦”轮廓。
- 对每层设置不同参数：
- `back`：波长更长、振幅更小、节奏更平缓。
- `mid`：中等波长与振幅。
- `front`：略短波长、振幅稍大，但仍控制在柔和范围内。
- 对同层不同线条增加少量相位偏移和局部振幅扰动，让每条线的波峰波谷位置不完全一致。

这一步会直接解决“像直线”的主因。

### 2. 调整层间景深，而不是只靠透明度

保留现有 3 层结构，但强化以下差异：

- `back` 层线更细、更浅、波长更长。
- `mid` 层作为过渡。
- `front` 层线稍粗、稍亮，起伏最明显。

同时收敛当前 `xJitter/scale` 的作用，让它只做辅助扰动，不再承担主要造型职责；主要形态交给真实 path。

### 3. 适当放大可见波形空间

在 `Home.vue` 中微调：

- 把 `hero-wave` 的高度从当前 `64px` 提升到一个更容易看出起伏的值。
- 必要时同步微调 `HeroWave` 的 `height` prop。
- 保持 `hero-fade` 与波线重叠自然，避免因为波形变高导致正文过渡生硬。

### 4. 保留当前配色方向

不改你的审美方向，继续维持“粉白、只有一丢丢粉”：

- 仍以 `color="white"` 作为首页默认。
- 保留顶部偏白、底部近景略粉的渐变逻辑。
- 若波形增强后显得太亮，再微调 `strokeOpacity` 上限，而不是加深颜色。

## 预期结果

完成后，首页底部分割会从“轻微抖动的直线”变成：

- 明显是连续起伏的柔和波线。
- 远中近三层的波长、振幅、线宽都有差异。
- 依旧是清透的白粉感，不会变成厚重海浪。
- 动效保留，但主体轮廓即使静止时也能看出是波，而不是直线。
