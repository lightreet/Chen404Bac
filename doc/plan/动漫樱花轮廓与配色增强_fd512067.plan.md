# 动漫樱花轮廓与配色增强

## 目标
把首页樱花进一步改成更像“花瓣”的动漫风效果：轮廓不再过于简单对称，而是更有樱花瓣特征；颜色不再只是淡粉空气感，而是更浓一点、更有动画插画中的粉色存在感。

## 新方向
- 轮廓：更像樱花瓣而不是简化水滴
  - 顶部更圆润
  - 中段更外扩、更饱满
  - 底部加入轻微凹口或分叉感，让花瓣更像真实樱花瓣
  - 左右保持大致对称，但加入细微不规则，避免图标感太强
- 颜色：更深、更有动漫感
  - 整体从当前偏浅粉白，调整为更明显的暖粉 / 玫粉过渡
  - 弱化“发白”中心，改成淡粉中心或粉白过渡
  - 前景层可以更饱和一点，远景层维持更淡，保留层次

## 修改范围
- 修改 [Chen404Fro/src/components/SakuraOverlay/SakuraOverlay.vue](d:\code_repo\Chen404\Chen404Fro\src\components\SakuraOverlay\SakuraOverlay.vue)
- 重点会改：
  - `PETAL_COLORS`
  - `DEPTH_PAINT`
  - `drawPetal()` 中的主花瓣路径与内部高光路径
- 保留现有：
  - 前景 / 中景 / 远景层级
  - 飘动节奏与较柔和的运动方向
  - 当前首页结构与 `Home.vue` 布局

## 实施步骤
- 重画 `drawPetal()` 的主轮廓：
  - 把当前简化花瓣外形改成更复杂的樱花瓣外轮廓
  - 调整底部收口，让它更像“花瓣尾部”而不是圆形收尾
- 重画内部高光层：
  - 去掉明显白块感
  - 改成更小、更粉、更贴合瓣形的高光区域
- 重调配色：
  - 提高主瓣中段与边缘的粉色饱和度
  - 让不同景深层使用不同强度的粉色，以免整体过艳但仍保留动漫感
- 保留并适配现有层次系统：
  - 前景花瓣颜色略深、轮廓略清晰
  - 远景花瓣颜色略淡、边缘更柔和

## 预期效果
- 花瓣第一眼更像樱花瓣，而不是装饰图标
- 颜色会比现在更有存在感，更接近动漫背景中粉色花瓣的感觉
- 保留当前已经有的前后层次，不会退回单一粒子感

## 风险控制
- 不会再大幅提高速度或风感，避免影响你现在已经认可的层次节奏
- 会控制饱和度，避免颜色加深后显得廉价或塑料感过重
