## 目标效果

- Hero 底部波浪像海浪一样“**一层一层**”有景深（远处更细更淡、近处更粗更明显）。
- 形态为“**多根线条抖动**”的水波线（不是单块填充波形）。
- 颜色：**淡粉透明**为主（你已选择）。
- 动画：持续波动、细微抖动，不卡顿；支持 `prefers-reduced-motion` 降级为静态。

## 方案概述（SVG 分层线条 + 滤镜抖动）

在首页 Hero 的 `hero-wave` 里改为：

- **3 个深度层**：`back` / `mid` / `front`
- 每层由 **N 条 stroke 波线**组成（例如 8/10/12 条），通过对同一条基础 path 做 y 偏移/轻微缩放，形成“层层海浪线”。
- 每层应用不同强度的 `feDisplacementMap`：
- back：低频、位移小、透明度低
- mid：中等
- front：高频、位移稍大、透明度更高
- `feTurbulence` 的 `baseFrequency/seed` 与位移 `scale` 做动画，形成“线条抖动”的水面效果。

## 具体落地步骤

1. **抽一个可复用组件**（推荐）

- 新建 `[d:\code_repo\Chen404\Chen404Fro\src\components\HeroWave\HeroWave.vue]`
- Props：`color="pink" | "white"`（本次默认 pink）、`height`、`intensity`（可选）
- 内部实现一个 SVG：
 - `<defs>`：线性渐隐 mask（上淡下实）、3 套 filter（back/mid/front）
 - `<g>`：每层循环渲染多条 `<path>`（stroke + opacity + stroke-width）

2. **替换首页波浪结构**

- 在 `[d:\code_repo\Chen404\Chen404Fro\src\views\Home\Home.vue]`
 - `hero-wave` 中用 `<HeroWave />` 替换当前静态 `<svg><path .../></svg>`

3. **颜色与渐隐融合**

- `HeroWave` 线条 stroke 采用淡粉透明（如 `rgba(255, 170, 200, 0.x)`）并随层级变化
- 保留/微调 `hero-fade`（封面到底部正文的渐隐）以保证波浪下方与 `var(--bg-primary)` 融合自然

4. **性能与可访问性**

- 控制线条数量（默认总线条数 25~35 条），避免过重
- 限制滤镜区域（`filterUnits="objectBoundingBox"` 或收紧 `x/y/width/height`）
- 加 `@media (prefers-reduced-motion: reduce)`：禁用 turbulence 动画，只保留静态线条

5. **验收点（你看效果时的检查项）

- 远/中/近 3 层明显：线条粗细、透明度、抖动强度逐层递进
- 不出现“大块填充”，是“多根线条在抖动”
- 底部与正文之间过渡柔和，不割裂
- 在 60fps 环境下无明显掉帧；低端设备也至少不明显卡顿

## 可能用到的关键技术点

- `SVG`：多 `<path>` stroke 叠加
- `filter`：`feTurbulence` + `feDisplacementMap`
- 动画：CSS keyframes（或 SVG `animate` 属性）驱动 filter 参数
- 降级：`prefers-reduced-motion`
