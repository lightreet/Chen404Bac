# 调整个人中心布局

## 目标
把 `个人中心` 顶部的多余功能块去掉，只保留必要的用户头部信息；同时把整个内容区域横向拉宽，让左侧菜单仍保持当前宽度，右侧各菜单内容页变宽。

## 计划
- 修改 [Chen404Fro/src/views/Profile/Profile.vue](d:\code_repo\Chen404\Chen404Fro\src\views\Profile\Profile.vue) 的顶部模板：
  - 删除顶部统计块 `banner-stats`（当前是“我的文章 / 草稿 / 已发布 / 收藏（预留）”）。
  - 删除顶部快捷入口 `banner-shortcuts`（当前是“我的文章 / 收藏 / 个人信息”按钮）。
  - 保留头像、昵称、账号、角色这类基础头部信息，让顶部卡片更简洁。
- 清理同文件里与顶部统计相关的脚本状态：
  - 去掉 `statsLoading`、`draftTotal`、`publishedTotal`、`favoriteTotal`、`totalArticles`。
  - 去掉 `loadArticleTotals()` 以及 `onMounted()` 中对它的调用。
  - 保留现有左侧菜单切换、文章列表加载、个人信息编辑逻辑不变。
- 调整同文件的布局样式，让主体区域更宽：
  - 放大 `.profile-center` 的宽度上限与视口占比，接近你截图里的蓝色范围。
  - 保持 `.profile-nav` 的 `240px` 宽度不变。
  - 让 `.profile-content` 继续 `flex: 1`，并减少 `.article-panel` 两侧额外内边距，使右侧内容页真正变宽。
  - 视需要同步微调 `.profile-split-scroll-box` 的间距，避免右侧卡片看起来仍然偏窄。
- 保持移动端断点逻辑不变，只在桌面端放大宽度，避免影响小屏布局。

## 关键改动点
- 当前总宽度由 `.profile-center { width: clamp(920px, 75vw, 1200px); }` 控制，这是右侧内容不够宽的主要原因。
- 当前左侧菜单已固定为 `.profile-nav { flex: 0 0 240px; width: 240px; min-width: 240px; }`，这部分会保持不动。
- 当前右侧内容还有 `.article-panel { padding: 0 16px; }`，这会进一步压缩可用宽度，也会一起收紧。

## 结果预期
- 顶部不再出现“我的文章 / 草稿 / 已发布 / 收藏（预留）”等冗余模块。
- 顶部不再出现重复的快捷入口按钮。
- 左侧菜单宽度保持现在视觉不变。
- 右侧“我的文章 / 收藏 / 个人信息”等展示面板明显变宽，更接近你截图蓝框中的目标宽度。
