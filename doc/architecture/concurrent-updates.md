# 编辑与账号更新的并发边界

文章编辑通过 `ArticleMapper.updateEditableFields` 更新白名单字段，不回写作者、浏览、点赞、评论计数。非管理员编辑不更新置顶和推荐字段。内容编辑使用 `article.version` 条件更新，成功后递增；影响行数不是 1 时返回 HTTP 409，停止后续标签、文件引用和知识切片写入。

详情接口返回 `version`，更新请求可以原样传回，过期编辑会被拒绝。为兼容已有客户端，未传版本时使用请求处理期间读到的版本，仍能检测两个请求读取同一版本后相互覆盖的情况；跨页面停留造成的过期编辑检测需要客户端传入读取时的版本。互动计数更新不递增编辑版本。

用户登录只写登录时间、IP，资料只写昵称、头像、简介及展示偏好，信任等级只写对应字段。资料与头像引用变更使用用户行锁保持一致。登录写入和密码修改均再次核对旧密码散列及账号启用状态：登录检查失败不签发令牌；密码条件更新失败返回冲突，不能覆盖另一条改密请求。

`ConcurrentUpdateMapperTest` 执行实际 Mapper SQL，验证交错操作保留彼此字段及两个同时提交的文章编辑只能成功一个。服务层测试验证冲突后不再进行文件、通知或令牌等后续操作。
