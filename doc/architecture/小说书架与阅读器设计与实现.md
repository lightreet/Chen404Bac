# 小说书架与阅读器设计与实现

> 当前状态：已落地并投入现有前后端架构；本文按 2026-08-14 源码与 Flyway 迁移核对。

## 1. 产品与权限模型

小说书架不是单纯的“私人上传页”，而是支持公开阅读、知友分享和私有保存的内容域。

| 操作 | 游客 | 普通登录用户 | 知友 | 合格所有者 | 管理员 |
| --- | --- | --- | --- | --- | --- |
| 浏览公开书籍 | 是 | 是 | 是 | 是 | 是 |
| 浏览知友书籍 | 否 | 否 | 是 | 自己的书可见 | 是 |
| 浏览私有书籍 | 否 | 否 | 否 | 是 | 是 |
| 导入/预览书籍 | 否 | 否 | 是 | 需具备知友查看能力 | 是 |
| 修改/删除书籍 | 否 | 否 | 否 | 是 | 是 |
| 保存进度和偏好 | 否 | 是 | 是 | 是 | 是 |

“合格所有者”指账号启用且仍具备 `friend-content:view` 的书籍导入者；失去知友资格后仍保留所有权和阅读权，但不能继续修改或删除，管理员可代管。导入入口由 `friend-content:view` 保护，不复用文章/旅行/音乐三个创作开关。书籍的 `public`、`friend`、`private` 可见性在查询、详情、目录、章节、搜索和资源访问中统一校验；无法识别的数据库可见性值按 `private` 处理，避免意外公开。

## 2. 前后端入口

### 2.1 前端路由

| 路径 | 说明 |
| --- | --- |
| `/bookshelf` | 公开书架；登录后按身份扩展可见书目，符合条件的用户可导入和管理自己的书籍 |
| `/reader/:bookId` | 阅读器；承载目录、章节正文、全文搜索、进度和阅读偏好 |

主要实现位于：

- `src/views/Reader/Bookshelf.vue`
- `src/views/Reader/Reader.vue`
- `src/api/reader.ts`
- `src/types/reader.ts`

### 2.2 后端边界

- 控制器：`ReaderLibraryController`
- 核心服务：`ReaderLibraryServiceImpl`
- 解析器：`ReaderBookParser`
- 异步执行器：`readerImportTaskExecutor`
- 数据表与模型：`reader_book`、`reader_book_asset`、`reader_chapter`、`reader_toc_item`、`reader_progress`、`reader_preference`

## 3. API 契约

| 方法与路径 | 鉴权 | 用途 |
| --- | --- | --- |
| `POST /reader/books/preview` | 知友/管理员 | 上传前解析预览，返回识别到的标题、作者等信息 |
| `POST /reader/books/import` | 知友/管理员 | 创建导入任务并返回书籍记录 |
| `GET /reader/books` | 可匿名 | 查询当前身份可见的书架 |
| `GET /reader/books/{bookId}` | 按书籍可见性 | 查询书籍详情和导入状态 |
| `PATCH /reader/books/{bookId}` | 合格所有者/管理员 | 修改元数据、封面和可见性 |
| `DELETE /reader/books/{bookId}` | 合格所有者/管理员 | 软删除书籍并清理业务引用 |
| `GET /reader/books/{bookId}/toc` | 按书籍可见性 | 获取多级目录 |
| `GET /reader/books/{bookId}/chapters/{chapterId}` | 按书籍可见性 | 获取章节正文 |
| `GET /reader/books/{bookId}/search` | 按书籍可见性 | 书内全文搜索 |
| `GET /reader/books/{bookId}/assets/{assetId}` | 按书籍可见性 | 获取书内插图等资源 |
| `GET/PUT/DELETE /reader/books/{bookId}/progress` | 登录用户 | 读取、保存或清除个人阅读进度 |
| `GET/PUT /reader/preferences` | 登录用户 | 读取或保存跨书籍阅读偏好 |

后端服务端鉴权是最终边界。前端隐藏按钮或路由守卫只用于体验优化，不能替代对象所有权和内容可见性的后端校验。

## 4. 导入与解析流程

```text
上传源文件
  -> 校验资格、格式与文件大小
  -> 原始文件以 NOVEL_SOURCE 受保护归属保存
  -> 创建 importing 状态的 reader_book
  -> readerImportTaskExecutor 异步解析
  -> 写入章节、目录和内嵌资源
  -> 成功改为 ready；失败改为 failed 并记录可诊断信息
  -> 提交后事务内创建管理员导入通知
```

当前支持：

- TXT
- EPUB
- HTML
- Markdown
- FB2

主要安全限制：

- 源文件最大 60 MB。
- ZIP/EPUB 单个 entry 最大 16 MB。
- 解压后总大小最大 120 MB。
- ZIP entry 数量最大 10,000。
- 书内资源总大小最大 48 MB。
- 解析过程中校验路径、压缩包规模和资源类型，防止路径穿越及压缩炸弹式资源消耗。

执行器当前为核心线程 1、最大线程 2、队列 100。应用启动时会恢复异常中断的导入任务，避免书籍永久停留在 `importing`。

## 5. 数据与迁移

| 迁移 | 作用 |
| --- | --- |
| `V2026072901` | 建立书籍、资源、章节、目录、进度和偏好表 |
| `V2026073001` | 增加书籍可见性，初始默认值为 `private` |
| `V2026073002` | 增加自定义封面能力 |
| `V2026073003` | 将新书籍默认可见性调整为 `public` |
| `V2026080302` | 允许同一源文件在软删除后重新导入 |

书籍状态至少覆盖 `importing`、`ready`、`failed`。章节内容与目录条目分开保存，以支持多级目录、精确跳转和书内搜索；内嵌图片等资源单独存储并通过受控 API 返回。

## 6. 阅读进度与偏好

阅读进度按用户和书籍维护，包含章节、块索引、字符偏移、locator 与内容版本等定位信息。内容发生变化时，前端和后端可依据版本与多级定位信息尽量恢复到稳定位置，而不是只保存一个像素滚动值。

阅读偏好是登录用户级设置，可跨书籍和设备恢复。前端保留必要的本地回退，后端持久化仍是登录态下的主事实来源。

## 7. 文件与安全

- 小说原始文件使用 `NOVEL_SOURCE` 归属，不能经普通公开文件地址绕过鉴权。
- 书内资源必须同时通过书籍可见性校验和资源归属校验。
- 受保护响应设置必要的内容类型与安全响应头，避免浏览器对未知内容进行危险嗅探。
- 删除、重新导入和解析失败场景必须同步处理业务记录、文件引用与软删除状态。

## 8. 前端交互与降级

- 书架对所有访客展示当前可见书籍，不把“没有知友资格”误判为整个功能不可访问。
- 导入采用预览、确认、异步状态轮询的流程；解析失败在书籍卡片上给出可理解状态。
- 阅读器支持目录跳转、章节阅读、书内搜索、进度恢复与偏好设置。
- 未登录用户可以阅读公开书籍，但不向后端写入个人进度；登录后才启用跨设备同步。

## 9. 当前边界与质量风险

- `ReaderBookParser` 和 `ReaderLibraryServiceImpl` 体积较大，格式解析、归档安全、持久化和权限逻辑存在继续拆分的价值；在建立格式夹具和事务回归测试前不宜进行一次性大重写。
- 异步导入依赖数据库、对象存储和执行器状态；单元测试通过不能替代真实大文件、损坏 EPUB、异常重启和对象存储故障的集成测试。
- 生成的前端 OpenAPI SDK 当前没有覆盖 reader 接口，实际调用由 `src/api/reader.ts` 承担；重新生成 SDK 前应以控制器和手写 API 为准。

## 10. 建议回归矩阵

1. 游客、普通用户、知友、所有者、管理员分别验证 public/friend/private 的列表、详情、章节、搜索和资源访问。
2. 对五种支持格式分别覆盖正常、空内容、损坏文件、超限文件和恶意压缩包。
3. 覆盖导入成功、失败、队列拒绝、服务重启恢复、软删除后重新导入。
4. 覆盖跨章节进度、内容版本变化、偏好跨设备同步和匿名阅读不写入服务端。
5. 验证原始文件和书内资源无法通过猜测 ID 或普通文件入口越权获取。
