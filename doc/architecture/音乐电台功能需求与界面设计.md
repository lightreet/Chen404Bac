# Sakura Radio 音乐功能需求与 UI 设计

## 1. 设计背景

Chen404 是一个带有强烈个人气质的网站。当前首页已经形成了清晰的视觉语言：樱花粉、柔雾背景、玻璃胶囊导航、手写感标题、Lyra 女仆悬浮助手和轻盈的文章卡片。音乐功能应当延续这个世界观，成为“网站里可以被打开的一间小电台”，而不是传统后台里的文件管理功能。

本功能定名为 **Sakura Radio**。它由两部分组成：

- **公开音乐馆**：主功能页面 `/music`，用于展示当前公开音乐、歌单、歌词和站长推荐语。
- **Lyra 随身播放器**：女仆工具栏上的音乐按钮，点击后弹出小播放器并自动播放默认电台。

音乐内容不放入管理员后台。参考旅行地图，音乐页面本身是公开内容页，普通用户可以浏览和播放，管理员在同一个页面看到编辑入口并直接维护内容。

### 1.1 现站点视觉依据

已确认线上站点 `https://www.chen404.cn/` 为 Chen404 Blog 前端入口。结合当前首页截图和现有前端代码，音乐页需要继承以下特征：

- 顶部导航是居中的玻璃胶囊，当前项用浅粉白底和粉色图标强调。
- 首页 Hero 是大图背景、粉白雾化遮罩、手写感大标题和柔波浪底部过渡。
- Lyra 位于页面左下区域，工具栏是小圆形按钮组。
- 页面主体内容居中，宽度克制，Discovery 区和文章卡片保留大量留白。
- 颜色不是高饱和粉色铺满，而是暖白、柔灰、浅粉和淡紫雾共同构成。

## 2. 产品目标

- 在网站主导航中新增“音乐馆”或“Sakura Radio”入口。
- 用户点击女仆音乐图标后弹出小播放器，并在用户点击触发后自动播放。
- `/music` 页面展示公开歌单、当前播放歌曲、歌词、推荐语和唱片架。
- 管理员在 `/music` 页面内联新增、编辑、上下架、排序歌曲和歌单。
- 支持完整歌曲资料：音频、封面、歌名、歌手、专辑、年份、语言、标签、推荐语、歌词。
- 歌词支持纯文本和 LRC 时间轴双模式。
- 视觉上延续 Chen404 当前首页：樱花、暖白纸感、玻璃胶囊、淡粉雾面、轻柔动效。

## 3. 非目标

- 首版不做用户评论、点赞、收藏、播放排行榜。
- 首版不做多用户投稿和审核。
- 首版不做第三方音乐平台同步。
- 首版不强制歌曲关联文章或旅行地图，只预留字段扩展。
- 首版不做复杂歌词编辑器，只做文本输入、LRC 校验和播放预览。

## 4. 用户与权限

### 4.1 普通访客

- 可访问 `/music`。
- 可查看已上架歌曲、公开歌单、封面、歌词、标签、推荐语。
- 可播放、暂停、切歌、拖动进度、调节音量、切换播放模式。
- 不可看到编辑入口。
- 不可访问保存、上传、删除、上下架接口。

### 4.2 管理员

- 拥有普通访客所有能力。
- 可在 `/music` 页面直接新增、编辑、上下架、排序歌曲。
- 可上传音频和封面。
- 可维护纯文本歌词或 LRC 歌词。
- 可维护歌单、默认电台和歌单歌曲排序。
- 可查看草稿、下架歌曲和非公开歌单。

## 5. 信息架构

### 5.1 主路由

- `/music`：公开音乐馆。
- `/music?playlist={id}`：指定歌单。
- `/music?track={id}`：指定歌曲并准备播放。

不新增传统后台路由。管理员编辑能力以内联按钮、抽屉、局部表单的形式出现在 `/music` 页面。

### 5.2 导航位置

建议在当前顶部导航中加入“音乐馆”：

- 位置建议：`旅行地图` 后，`受信申请` 前。
- 图标建议：Element Plus `Headset`、`Service` 或 `Microphone`。如果图标库没有合适图标，可优先使用 `Headset`。
- 文案建议：桌面端显示“音乐馆”，移动端显示“音乐馆”。

## 7. 视觉设计样式说明

### 7.1 整体气质

音乐页应像 Chen404 首页自然延伸出来的一页：柔软、梦感、但控件清晰。它不是酷炫播放器，也不是后台表格。用户感受到的是“站长的私人电台”和“Lyra 递来一张唱片”。

关键词：

- 樱花粉
- 暖白纸感
- 柔雾玻璃
- 唱片架
- 夜读
- 私人推荐
- 轻盈陪伴

### 7.2 色彩

沿用现有色彩体系：

- 主色：`#fb7299`
- 主色浅层：`#ff85a7`
- 主色深层：`#e44d78`
- 页面背景：`#f4f5f7`
- 暖白表面：`rgba(255, 255, 255, 0.92)`
- 玻璃表面：`rgba(255, 251, 253, 0.72)`
- 边框：`rgba(255, 220, 232, 0.48)`
- 主文字：`#4f3c46`
- 次文字：`#8d7b84`
- 点缀冷色：淡紫雾 `#c7bdd9`

音乐页不要变成单一粉色页面。粉色用于激活态、播放态、重点按钮、歌词高亮和少量阴影。主体仍是暖白、纸感、柔灰和淡紫雾。

### 7.3 Hero

Hero 延续当前首页模式：

- 大幅背景图。
- 半透明粉白雾遮罩。
- 花瓣或柔光可以存在，但不可遮挡标题。
- 标题使用现有手写感 display 字体。
- 副标题使用清晰白色或浅暖白。
- Hero 高度建议桌面端 `68vh-76vh`，比首页略短，让用户更快进入播放器。
- Hero 底部可继续使用柔波浪过渡。

建议文案：

- 标题：`Sakura Radio`
- 副标题：`今晚，Lyra 为你调好一首歌。`
- 备用中文标题：`音乐馆`

默认背景建议：

- 樱花街景、唱片架、夜晚书桌、柔光房间。
- 避免强黑胶酒吧风、霓虹赛博风、强对比舞台风。

### 7.4 主播放器

主播放器是页面视觉核心。建议使用左右分栏：

- 左侧：封面唱片区。
- 右侧：歌曲信息、推荐语、控件、歌词。

桌面尺寸：

- 容器宽度：`min(1120px, calc(100vw - 48px))`
- 圆角：`28px-32px`
- 背景：暖白玻璃 + 微弱樱花渐变。
- 阴影：柔和玫瑰阴影，避免深灰重阴影。

封面：

- 使用正方形封面。
- 播放中可做唱片轻微旋转。
- 暂停时旋转停止。
- 封面缺失时使用默认唱片封面。

控件：

- 播放按钮为主要视觉按钮，圆形，樱花粉渐变。
- 上一首、下一首、模式、音量为轻按钮。
- 进度条使用樱花粉填充，轨道为浅粉灰。
- 所有按钮需要 hover、focus、disabled 状态。

### 7.5 歌词

LRC 歌词：

- 当前句高亮，颜色 `#e44d78` 或 `#fb7299`。
- 上下句使用 `#8d7b84`，透明度降低。
- 滚动动画控制在 `180ms-260ms`，不要过度跳动。
- 当前句可有极淡的粉色背景，不做粗重色块。

纯文本歌词：

- 使用纸张式文本容器。
- 保留换行。
- 最大高度内滚动。
- 行高建议 `1.8`。

空歌词：

- 显示安静空状态：`这首歌还没有写下歌词。`

### 7.6 歌单区

歌单应像一排轻量胶囊或小唱片标签：

- 当前歌单使用樱花粉浅底和粉色文字。
- 非当前歌单使用暖白玻璃底。
- 每个歌单可显示名称、歌曲数、短描述。
- 管理员可看到“管理歌单”入口。

不建议首版做复杂侧栏。当前站点首页是居中内容流，音乐页也应保持中央内容结构。

### 7.7 唱片架卡片

唱片卡片要比文章卡片更轻、更可浏览：

- 卡片圆角：`18px-22px`
- 封面比例：`1:1`
- 卡片宽度：桌面 `220px-260px`
- 网格：`repeat(auto-fill, minmax(220px, 1fr))`
- 推荐语最多两行。
- 标签使用浅粉胶囊。
- 当前播放卡片增加粉色描边和轻微上浮。

管理员操作不要常驻抢视觉。建议 hover 或卡片右上角显示小图标按钮：

- 编辑
- 上架/下架
- 移入歌单
- 拖拽排序

### 7.8 Lyra 小播放器

小播放器应与现有聊天面板同源，但更紧凑：

- 宽度：桌面 `320px-360px`
- 圆角：`22px-26px`
- 背景：白粉玻璃。
- 标题：`Sakura Radio`
- 不使用大面积黑色播放器风格。
- 如果 Lyra 靠左，小播放器出现在右侧；如果 Lyra 靠右，小播放器出现在左侧。
- 移动端小播放器固定在底部，宽度 `min(92vw, 360px)`。

小播放器与 `/music` 页面共享播放状态：

- 音乐页点歌后，小播放器打开显示同一首。
- 小播放器切歌后，音乐页当前播放状态同步。
- 关闭小播放器不停止播放。
- 暂停音乐后，音乐图标停止律动。

### 7.9 动效

只保留表达状态的动效：

- 播放中封面缓慢旋转。
- 音乐图标播放中轻微律动。
- 歌词切换平滑滚动。
- 卡片 hover 轻微上浮。
- 播放按钮点击有短反馈。

动效时间建议：

- hover：`180ms-240ms`
- 面板展开：`220ms-280ms`
- 歌词滚动：`180ms-260ms`
- 封面旋转：`18s-28s` 一圈，线性。

需支持 `prefers-reduced-motion`，减少或关闭旋转和律动。

## 8. 歌曲资料模型

### 8.1 MusicTrack

- `id`：歌曲 ID。
- `title`：歌名。
- `artist`：歌手。
- `album`：专辑，可为空。
- `releaseYear`：发行年份，可为空。
- `language`：语言，可为空。
- `genre`：风格，可为空。
- `tags`：标签列表。
- `audioFileId`：音频文件 ID。
- `audioUrl`：前台播放 URL。
- `coverFileId`：封面文件 ID，可为空。
- `coverUrl`：封面 URL，可为空。
- `lyricType`：`plain` 或 `lrc`。
- `lyrics`：歌词内容。
- `lyricSource`：歌词来源备注，可为空。
- `recommendation`：站长推荐语。
- `moodText`：心情短句，可为空。
- `status`：`draft`、`published`、`archived`。
- `sortOrder`：排序权重。
- `createdAt`：创建时间。
- `updatedAt`：更新时间。

### 8.2 MusicPlaylist

- `id`：歌单 ID。
- `name`：歌单名称。
- `description`：歌单描述。
- `coverFileId`：歌单封面文件 ID，可为空。
- `coverUrl`：歌单封面 URL，可为空。
- `openingText`：电台开场文案。
- `isDefault`：是否默认电台。
- `isPublic`：是否公开。
- `sortOrder`：排序权重。
- `createdAt`：创建时间。
- `updatedAt`：更新时间。

### 8.3 MusicPlaylistTrack

- `playlistId`：歌单 ID。
- `trackId`：歌曲 ID。
- `sortOrder`：歌单内排序。

## 9. 接口边界

### 9.1 公开接口

- `GET /music/tracks`：获取公开歌曲列表。
- `GET /music/tracks/{id}`：获取公开歌曲详情。
- `GET /music/playlists`：获取公开歌单列表。
- `GET /music/playlists/{id}`：获取公开歌单详情与歌曲。
- `GET /music/radio/default`：获取默认电台歌单，用于女仆播放器首次播放。

公开接口只返回 `published` 歌曲和 `isPublic = true` 歌单。

### 9.2 管理接口

管理接口需要管理员权限。

- `POST /music/tracks`：新增歌曲。
- `PUT /music/tracks/{id}`：更新歌曲。
- `PATCH /music/tracks/{id}/status`：上下架或归档歌曲。
- `DELETE /music/tracks/{id}`：删除歌曲，首版建议仅允许未被歌单引用的歌曲物理删除。
- `POST /music/playlists`：新增歌单。
- `PUT /music/playlists/{id}`：更新歌单。
- `PUT /music/playlists/{id}/tracks`：保存歌单歌曲和排序。
- `PATCH /music/playlists/{id}/default`：设置默认电台。

音频和封面上传复用现有文件上传能力，保存歌曲时引用文件 ID。

## 10. 歌词规则

- `plain`：前台静态展示，保留换行。
- `lrc`：前台解析时间戳并随播放高亮滚动。
- LRC 支持 `[mm:ss.xx]文本` 基础格式。
- 管理员保存 LRC 时进行格式校验。
- 格式错误不应导致整页崩溃，前台可降级为纯文本展示。
- 无歌词时显示安静空状态。

## 11. 播放状态

前端应建立统一音乐播放状态模块，供 `/music` 页面和 `Live2D` 小播放器共享。

状态包含：

- 当前队列。
- 当前歌曲。
- 当前播放时间。
- 播放/暂停状态。
- 音量。
- 播放模式。
- 当前歌单 ID。

持久化建议：

- 音量、播放模式、最近歌单存入 `localStorage`。
- 播放进度不需要跨会话长期保存，最多在当前页面生命周期内保留。

## 12. 错误与边界

- 没有公开歌曲：音乐页显示空状态，管理员看到新增入口，普通用户看到温和提示。
- 默认歌单为空：女仆音乐图标点击后弹出提示，不进入播放中状态。
- 音频加载失败：跳过当前歌曲并提示；如果队列都失败，停止播放。
- 歌曲下架：不再进入新队列；已在当前队列中的歌曲可在下一次刷新后消失。
- 封面缺失：使用默认唱片封面。
- 移动端：小播放器固定在可视区域内，避免遮挡 Lyra 或核心阅读内容。

## 14. 首版决策

- 音乐页公开给所有访客访问，编辑能力只对管理员开放。
- 首版支持多个公开歌单，并要求存在一个默认电台歌单。
- 上传音频和封面沿用现有文件上传、文件引用和存储配置。
- 音乐模块只保存文件 ID 和业务元数据。
- 音乐页接入现有功能 Hero 配置体系，新增 `music` 配置 key，未配置时使用默认 Sakura Radio 背景。
- 导航新增“音乐馆”，Lyra 工具栏新增音乐按钮。
