# 文章列表查询与权限边界

公开文章、我的文章、点赞和收藏列表统一使用数据库计数与分页。`ArticleMapper.xml` 共用列表字段投影和读取范围片段；正文、渲染 HTML、密码不进入列表查询。`PageBounds` 统一处理缺省页码、每页上限，文章默认 10 条，管理员列表默认 20 条，上限 100 条。

`ArticleReadScope` 从已加载用户构造可读范围。管理员和文章作者的特殊权限、账号启停状态、可见性允许值在此集中解析，`AccessService.canViewArticle` 也使用同一对象。SQL 与对象检查通过真实数据库矩阵测试保持一致：匿名、读者、知友、管理员、停用账号，草稿/发布/回收站，以及未知或缺失可见值均被覆盖。

公开列表仍只显示已发布文章；“我的文章”按作者和可选状态筛选；点赞/收藏保留关系创建时间顺序，但在数据库中先排除无权访问或已删除文章再分页。公开搜索仍只匹配标题，我的文章搜索同时匹配标题和摘要。相同时间使用文章 ID 作为稳定排序补充。

`ArticlePageMapperTest` 在 1,200 条候选数据中读取第二页，验证查询为一次 COUNT 和一次取页 SQL；这说明数据库往返次数不再随候选数量增加，并不意味着 COUNT 本身为常数时间。后续索引调整应依据实际数据量及执行计划，不能仅凭 SQL 形状增加索引。
